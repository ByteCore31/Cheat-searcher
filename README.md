# 🛡️ Cheat Search

**Проверка компьютера на читы для Minecraft.** Консольная программа для Windows: ищет чит-клиенты, лоадеры и их следы — и по названиям файлов, и по их содержимому.

Создана для честной проверки игроков: удобна серверам и администраторам.

## 📥 Как запустить

1. Открой раздел [**Releases**](../../releases) и скачай `Cheat Search.exe` и `cheats.json`.
2. Положи **оба файла в одну папку**.
3. Запусти `Cheat Search.exe`.
4. Нажми **1**, чтобы начать проверку. Для полной проверки нажми **3** (запуск от администратора).

> Python устанавливать не нужно — всё уже внутри `.exe`.

---

## 🔍 Что проверяет

- **Запущенные программы** — имя, заголовок окна, команду запуска.
- **Файлы и папки** — Рабочий стол, Загрузки, Документы, AppData, `.minecraft`, папки лаунчеров (Prism, TLauncher, Lunar, CurseForge, Modrinth) и другие диски.
- **Корзину, «Недавние», логи Minecraft** — следы уже удалённых читов.
- **Историю запусков** — Prefetch и журнал BAM (нужны права администратора).
- **Исключения Защитника Windows.**

## 🧠 Чем отличается от простого поиска по названию

Переименовать файл легко, а его содержимое — нет. Поэтому Cheat Search смотрит **внутрь**:

- внутри `.jar` — код известных читов и чит-модули (KillAura, TriggerBot…), даже у обфусцированных сборок;
- внутри `.exe` и `.dll` — названия чит-клиентов, так находятся **переименованные лоадеры**;
- **инжект** в запущенную игру: `-javaagent` и чужие DLL;
- **отпечатки SHA-256** известных читов.

---

## 📝 База читов

Список читов лежит в `cheats.json` рядом с программой. Его можно **пополнять без пересборки** `.exe`:

- `cheat_clients` — названия чит-клиентов;
- `suspicious` — подозрительные слова;
- `allowed` — разрешённое (не считается читом);
- `hashes` — отпечатки SHA-256.

---

## ⚠️ Честно о возможностях

Программа ищет по известным признакам и **не гарантирует 100%**. Она может не найти приватные самописные читы, читы на уровне драйвера или следы, стёртые переустановкой Windows. Это хорошая первая проверка, но не замена ручному осмотру.

Программа **ничего не удаляет сама** — только показывает находки (удаление найденного — по отдельной кнопке, файлы уходят в Корзину).
